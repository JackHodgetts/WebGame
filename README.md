## WebGameDevelopment

Maze Ascendancy is a 3D web game made by Jack Hodgetts using Three.js, JS, HTML, CSS, and ES6.

## How to play:
- W - Move Forward
- S - Move Backward
- A - Turn Left
- D - Turn Right
- E - Interact
- Mouse Click - Press Buttons on the screen

## How to Win:
Find the four buttons that are around the maze and leave through the door in 5 minutes. The time you have remaining is your score which is saved on the server in seconds.

## Key Points:
- Website Design - Index Page, Game Page, Game loading Page, 404 Page, Login Page, and Register Page.
- Game Assets - Maze Landscape
- Game Material - Maze Texture and Skybox
- Game Animation - Button moves downwards, Camera moves, and Door moves
- Game interaction - Pressing the buttons, moving forwards and backwards, and turning left and right
- Game UI - Timer
- Game mechanism - Moving around the maze, Turning, pressing the button, timer, restarting, and replaying after you win. 
- Responsive Web design
- Game Server working and deploying using Node.js with 404 page being deployed
- Game Website login and register working
- Data storage - login and game store are stored and saved on the server
- Game Data storage - data is secure with the passed being bcrypt 
- Game Audio - Background sound and ding when the button is pressed
- Game working on Google Chrome
- Game has a restart button
- Game has a loading page
