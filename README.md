

# Maze Ascendancy

A 3D web-based maze game developed using JavaScript and Three.js, featuring user authentication, server-side data storage, and responsive web design.

## Overview

Maze Ascendancy was a university project focused on creating a web-based 3D game supported by server-side functionality for user management and game data storage.

The project combined front-end web development, 3D game development, and back-end server functionality. Players navigate through a 3D maze while interacting with gameplay mechanics such as buttons, timers, and environmental elements. User accounts and game data were stored and managed through a server-based system.

The application was designed to be responsive across different screen sizes and deployed as a fully functional web application.

## Challenges and Solutions

### Developing a Full Web Application Stack

The project required combining front-end web development, game development, and server-side functionality within a single application.

This involved implementing responsive web pages, user authentication systems, and game data storage while maintaining a consistent user experience throughout the application.

### Implementing 3D Collision Detection

One of the most technically challenging aspects of the project was creating reliable collision detection within the 3D maze environment.

This was solved using a raycasting-based system that continuously checked the player's surroundings and prevented movement through maze walls when collisions were detected.
